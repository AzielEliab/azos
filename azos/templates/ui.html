About

      
AZ Interface is the local control surface for this ethics-coded remote shell. Commands stay in a session folder under .azos in the directory where you started azos ui.

      
Author: Aziel Eliab.

      
What a session does

      
    
        
  • A token is issued only after five checks pass: definition, evidence, impact, integrity, and responsibility.
    • 
        
  • Each command is checked again. The session folder is the workspace.
    • 
        
  • Halt stops new commands. The watch (Lumen) stays on and can still revoke a token or purge .azos.
    • 
        
  • Purge deletes that .azos folder only, after you type CONFIRM.
    • 
      

      
Integrity precedes execution.
